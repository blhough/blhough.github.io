Is it faster to index an array or use a switch?

25 Feb 2026

25 Feb 2026 ~4 mins .NET, C#, Performance

Suppose you are mapping small integer codes to fixed strings—think log levels or enum-like ordinals. Two obvious shapes are a readonly string[] plus bounds check, and a switch expression with a default that falls back to ToString(). This sample post shows that shape with code blocks and a BenchmarkDotNet-style results table.

Before you scroll to the numbers, pick a horse: do you expect materially different throughput on modern JIT for dense integer keys?

Code

Array-backed lookup:

static readonly string[] Strings =
[
    "Trace",
    "Debug",
    "Information",
    "Warning",
    "Error",
    "Critical",
    "None",
];

public string Array(int i)
    => i < Strings.Length
        ? Strings[i]
        : i.ToString();

And the switch form (for dense 0..N keys the compiler can emit a jump table, which is the same mental model as indexing): 

public string Switch(int i)
    => i switch
    {
        0 => "Trace",
        1 => "Debug",
        2 => "Information",
        3 => "Warning",
        4 => "Error",
        5 => "Critical",
        6 => "None",
        _ => i.ToString(),
    };

Everything that follows is illustrative: treat the table as showing the shape of a BenchmarkDotNet summary, not a reproducibility claim.

Results

Method i Mean Error StdDev Median
Array 0 0.63 ns 0.01 ns 0.04 ns 0.62 ns
Switch 0 0.29 ns 0.04 ns 0.19 ns 0.40 ns
Array 3 0.34 ns 0.03 ns 0.17 ns 0.24 ns
Switch 3 0.15 ns 0.04 ns 0.20 ns 0.02 ns
Array 6 0.51 ns 0.04 ns 0.20 ns 0.62 ns
Switch 6 0.42 ns 0.01 ns 0.03 ns 0.41 ns
Array 7 1.23 ns 0.01 ns 0.03 ns 1.23 ns
Switch 7 1.10 ns 0.01 ns 0.04 ns 1.10 ns

At sub-nanosecond scales the ranking flips with noise, branch prediction, and alignment. For i == 7 both paths pay for ToString(), which dominates the comparison. The practical takeaway is unchanged: choose readability and reuse unless profiling says otherwise.

Benchmark class:

[LongRunJob]
public class Bench
{
    public static IEnumerable<int> Values() => [0, 1, 2, 3, 4, 5, 6, 7];

    static readonly string[] Strings =
    [
        "Trace",
        "Debug",
        "Information",
        "Warning",
        "Error",
        "Critical",
        "None",
    ];

    [Benchmark, ArgumentsSource(nameof(Values))]
    public string Array(int i)
        => i < Strings.Length
            ? Strings[i]
            : i.ToString();

    [Benchmark, ArgumentsSource(nameof(Values))]
    public string Switch(int i)
        => i switch
        {
            0 => "Trace",
            1 => "Debug",
            2 => "Information",
            3 => "Warning",
            4 => "Error",
            5 => "Critical",
            6 => "None",
            _ => i.ToString(),
        };
}
