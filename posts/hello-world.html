If you can edit HTML, you can maintain this blog. The homepage lists recent posts; each post is a separate file; feed.xml is a static Atom feed you can update when you publish.

Host it anywhere that serves files: object storage with a CDN, GitHub Pages, Neocities, or your own web server. No build step required.

The goal is durability: fewer moving parts means fewer things to break.
